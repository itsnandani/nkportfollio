# Assets

This portfolio uses **no external image files**. All visual elements are generated with CSS:

- **Code window illustration** in the hero section — built with HTML and CSS
- **Project dashboard mockups** — built with HTML and CSS
- **Box Model diagram** in Task 2 — built with nested HTML containers and CSS
- **Icons and decorative elements** — CSS-generated shapes, borders, and gradients

This approach ensures the project is fully self-contained with no external dependencies, broken images, or missing assets.
